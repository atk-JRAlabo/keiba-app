# 着順シミュレーター(無料・共有版)

Claudeを介さずに、単体のWebアプリとして動きます。
**ホスティングは無料(GitHub Pages)**。友達に共有してもあなたに課金は発生しません。

## 無料でできること・課金が要ること

| 機能 | 費用 |
|---|---|
| 手入力・CSV読み込み・シミュレーション本体・予想ログ | **完全無料**(誰でもすぐ使えます) |
| 画像から読み込む(AI解析・騎手Web検索) | 使いたい人が**自分のAnthropic APIキー**を登録すれば利用可(その人の従量課金) |

つまり、あなたが友達に配っても、あなたには一切費用がかかりません。
画像読み込み機能を使いたい人は、各自でキーを設定するだけです(下記参照)。

## デプロイ手順(スマホだけでOK・ターミナル不要)

### 1. GitHubアカウントを作る
まだ持っていなければ https://github.com/signup (スマホのブラウザでOK)

### 2. 新しいリポジトリを作る
1. github.com にログイン→右上の「+」→「New repository」
2. Repository name: `keiba-app`(このzipのvite.config.jsのbase設定と合わせるため、名前はこのままがおすすめです)
3. 「Public」のまま「Create repository」

### 3. ファイルをアップロードする
1. 作ったリポジトリの画面で「Add file」→「Upload files」
2. このプロジェクトの中身(このzipを展開したもの)を全部選んでドラッグ&ドロップ、またはファイル選択
   - フォルダごとアップロードできない場合は、`.github/workflows/deploy.yml` や `src/main.jsx` のように、パスを保ったまま1つずつ「Create new file」で作成し、中身を貼り付けてもOKです
3. 「Commit changes」で保存

### 4. GitHub Pagesを有効にする
1. リポジトリの「Settings」タブ→左メニュー「Pages」
2. 「Build and deployment」の「Source」を **「GitHub Actions」** に変更
3. 保存(これだけでOK。あとはコードをpushするたびに自動でビルド・公開されます)

### 5. デプロイを確認する
1. リポジトリの「Actions」タブを開く
2. 「Deploy to GitHub Pages」が実行されるので、完了(緑のチェック)まで待つ(数分)
3. 完了したら「Settings」→「Pages」に表示されるURL(例: `https://ユーザー名.github.io/keiba-app/`)を開く

### 6. スマホのホーム画面に追加する
1. 上記URLをスマホのブラウザ(Safari/Chrome)で開く
2. 共有ボタン→「ホーム画面に追加」

これで友達にもこのURLを送るだけで、同じように使えます。

## 画像読み込み(AI機能)を使いたい人向け

アプリ内の「出走表」→「AI機能の設定」を開き、Anthropicの https://console.anthropic.com/settings/keys で発行したAPIキーを入力して保存してください。

- キーはその人のブラウザ内(localStorage)にのみ保存され、どこにも送信されません
- 画像解析・騎手検索の費用は、キーを登録した本人のAnthropicアカウントに課金されます(このアプリの持ち主には一切かかりません)
- 設定しなくても、手入力・CSV読み込みでシミュレーションは問題なく使えます

## 注意点

- 予想の記録・騎手キャッシュ・APIキーは、それぞれの端末のブラウザ内(localStorage)に保存されます。ブラウザのデータを消すと消えます
- 複数の端末で使っても、データは同期されません(端末ごとに別々です)
